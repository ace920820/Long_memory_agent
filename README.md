# 智能长期记忆对话系统

一个基于长期记忆的智能对话系统，通过管理和利用历史对话内容，提供个性化且连贯的对话体验。系统能够像人类一样形成并利用长期记忆，实现更自然的人机交互。

## 🌟 主要特点

### 📚 知识库管理（新增）
- **文档管理**
  - 多格式文档支持（TXT、DOCX、PDF、MD）
  - 文档上传、预览、编辑和删除
  - 智能文档分段与索引
  - 基于语义的文档内容检索
- **内容处理**
  - 智能文本分块：基于语义的递归切分
  - 动态块大小调整：保持语义完整性
  - 智能重叠处理：确保上下文连贯
  - 文档内容实时预览

### 🧠 智能记忆管理
- **记忆管理界面**
  - 批量管理功能
  - 高级检索功能
  - 记忆详细信息显示
  - 优化的删除操作流程
- **向量模型**
  - BGE (BAAI General Embedding) 中文向量模型
  - bge-small-zh-v1.5 作为默认模型
  - 512维向量表示
  - 优秀的中文语义理解能力
- **记忆操作**
  - 智能记忆拆分
  - 自动记忆清理
  - 记忆重构优化

### 🤖 Agent 系统（新增）
- **角色定制**
  - 可配置的角色设定
  - 动态人格调整
  - 多维度角色属性
  - 情感状态管理
- **对话策略**
  - 基于角色的回复生成
  - 上下文感知的语气调整
  - 多轮对话一致性维护
  - 情感智能响应
- **知识整合**
  - 角色知识库管理
  - 动态知识更新
  - 个性化知识应用
  - 记忆与知识融合
- **交互增强**
  - 主动式对话引导
  - 多模态交互支持
  - 个性化表达方式
  - 自然对话流控制

### 💬 对话能力
- **上下文感知**：多层次上下文构建（关键、相关、背景信息）
- **记忆融合**：智能将相关记忆融入对话生成
- **个性化回复**：基于用户历史偏好的回答生成
- **对话连贯性**：维护最近对话历史，确保交互连贯

### 🛠 知识检索增强
- **向量索引**：基于FAISS的高效向量检索
- **三阶段检索策略**
  - 第一阶段：BGE Embedding 向量检索（20%权重）
  - 第二阶段：BGE-Rerank 精确重排序（50%权重）
  - 第三阶段：记忆优先级评分（30%权重）
  - 加权融合策略：综合考虑向量相似度、重排序分数和记忆优先级
- **记忆优先级机制**
  - 时间因子：改进的多阶段时间衰减计算
    - 24小时内：缓慢线性衰减，保持高优先级
    - 1周内：中等速度衰减，保持中等优先级
    - 1周后：对数衰减，长期保持基础优先级
  - 重要性因子：不同类型记忆的权重区分
  - 访问因子：基于访问频率的重要性评估
  - 自动清理：优先级阈值过滤
- **智能匹配**
  - 基于语义的文档匹配
  - 动态相似度阈值
  - 详细的匹配得分日志
- **持久化存储**：文档和索引的本地持久化

### 🛠️ 系统架构
- **模块化设计**：核心功能解耦，便于扩展
- **配置驱动**：通过YAML配置文件管理系统参数
- **完整日志**：详细的运行日志，便于调试和监控
- **RESTful API**：标准的HTTP接口支持
- **大模型支持**：
  - 支持 Deepseek API 接入
  - 灵活的模型配置
  - 环境变量动态加载
  - 多模型切换能力

## 🚀 快速开始

### 环境要求
- Python 3.8+
- PyTorch 1.8+
- Transformers 4.30+
- 现代浏览器（支持ES6+）
- 依赖包：
  - sentence-transformers>=2.2.0
  - transformers>=4.30.0
  - torch>=1.10.0
  - faiss-cpu
  - flask
  - pyyaml
  - python-dotenv
  - dashscope  # Deepseek API支持

### 环境变量配置
在运行系统前，需要配置以下环境变量：

```bash
# 基础环境变量
PYTHONUNBUFFERED=1

# Deepseek API配置
DASHSCOPE_API_KEY=your_api_key  # 替换为你的API密钥
DASHSCOPE_MODEL=qwen-plus       # 可选模型：qwen-plus, qwen-max, 等
```

你可以通过以下方式设置环境变量：

1. 在系统环境变量中设置
2. 在 `.env` 文件中配置
3. 在启动命令中指定：
```bash
export DASHSCOPE_API_KEY=your_api_key
export DASHSCOPE_MODEL=qwen-plus
python main.py
```

### 安装步骤

1. 克隆项目
```bash
git clone https://github.com/ace920820/long-memory-chat.git
cd long-memory-chat
```

2. 安装依赖
```bash
pip install -r requirements.txt
```

3. 初始化配置和记忆文件
```bash
python scripts/init_memory_file.py
```

4. 启动服务
```bash
python main.py
```

5. 访问系统
浏览器打开 `http://localhost:5000`

## ⚙️ 配置说明

系统配置（config/config.yaml）：
```yaml
server:
  host: "0.0.0.0"
  port: 5000

memory:
  max_memories: 1000
  clean_threshold: 0.85
  similarity_threshold: 0.45
  access_history_limit: 10  # 保存最近访问历史的数量
  priority_weights:
    time: 0.3
    importance: 0.4
    access: 0.3
```

## 🔌 API接口

### 记忆管理接口
- `POST /api/memories/access`: 记录记忆访问
- `POST /api/memories/priority`: 更新记忆优先级
- `POST /api/memories/clean-low-priority`: 清理低优先级记忆

### 知识库接口
- `POST /api/documents`: 添加新文档
- `PUT /api/documents/{id}`: 更新文档
- `DELETE /api/documents/{id}`: 删除文档
- `GET /api/documents/search`: 检索相关文档
