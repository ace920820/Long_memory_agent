# 智能长期记忆对话系统

一个基于长期记忆的智能对话系统，通过管理和利用历史对话内容，提供个性化且连贯的对话体验。系统能够像人类一样形成并利用长期记忆，实现更自然的人机交互。

## 🌟 主要特点

### 🧠 智能记忆管理
- 使用先进的 BGE (BAAI General Embedding) 中文向量模型
  - 采用 bge-small-zh-v1.5 作为默认向量模型
  - 512维向量表示
  - 优秀的中文语义理解能力
- 多类型记忆支持（事实、偏好、对话）
- 记忆的自动存储与检索
- 智能记忆重构与优化
- 自动清理重复/无效记忆
- 记忆拆分功能

### 💬 对话能力
- **上下文感知**：多层次上下文构建（关键、相关、背景信息）
- **记忆融合**：智能将相关记忆融入对话生成
- **个性化回复**：基于用户历史偏好的回答生成
- **对话连贯性**：维护最近对话历史，确保交互连贯

### 🛠 知识检索增强
- **向量索引**：基于FAISS的高效向量检索
- **文档管理**：支持动态添加、更新和删除文档
- **相似度匹配**：智能筛选相关知识片段
- **持久化存储**：文档和索引的本地持久化

### 🛠️ 系统架构
- **模块化设计**：核心功能解耦，便于扩展
- **配置驱动**：通过YAML配置文件管理系统参数
- **完整日志**：详细的运行日志，便于调试和监控
- **RESTful API**：标准的HTTP接口支持

## 🚀 快速开始

### 环境要求
- Python 3.8+
- PyTorch 1.8+
- Transformers 4.0+
- 现代浏览器（支持ES6+）
- 依赖包：
  - sentence-transformers
  - flask
  - pyyaml
  - python-dotenv

### 安装步骤

1. 克隆项目
```bash
git clone https://github.com/ace920820/long-memory-chat.git
cd long-memory-chat
```

2. 安装依赖
```bash
pip install -r requirements.txt
```

3. 初始化配置和记忆文件
```bash
python scripts/init_memory_file.py
```

4. 启动服务
```bash
python main.py
```

5. 访问系统
浏览器打开 `http://localhost:5000`

## 💡 核心功能说明

### 记忆管理系统
- **记忆存储**：JSON格式存储，支持多用户
- **记忆检索**：基于向量相似度的智能检索
- **优先级机制**：
  - 时间因子：基于最近访问时间的衰减计算
  - 重要性因子：不同类型记忆的权重区分
  - 访问因子：基于访问频率的重要性评估
  - 自动清理：优先级阈值过滤
- **访问统计**：
  - 访问次数统计
  - 首次/最近访问时间记录
  - 访问历史追踪
  - 持久化存储

### RAG检索系统
- **文档索引**：
  - 向量化存储
  - 实时更新
  - 持久化管理
- **智能检索**：
  - 相似度计算
  - 阈值过滤
  - Top-K 选择
- **文档操作**：
  - 批量导入
  - 动态更新
  - 删除支持

## ⚙️ 配置说明

系统配置（config/config.yaml）：
```yaml
server:
  host: "0.0.0.0"
  port: 5000

memory:
  max_memories: 1000
  clean_threshold: 0.85
  similarity_threshold: 0.45
  access_history_limit: 10  # 保存最近访问历史的数量
  priority_weights:
    time: 0.3
    importance: 0.4
    access: 0.3
```

## 🔌 API接口

### 记忆管理接口
- `POST /api/memories/access`: 记录记忆访问
- `POST /api/memories/priority`: 更新记忆优先级
- `POST /api/memories/clean-low-priority`: 清理低优先级记忆

### 知识库接口
- `POST /api/documents`: 添加新文档
- `PUT /api/documents/{id}`: 更新文档
- `DELETE /api/documents/{id}`: 删除文档
- `GET /api/documents/search`: 检索相关文档
